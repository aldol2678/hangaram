# 한가람 설계 요약

정본: Notion 《한가람 · 한강 월드맵 개발 설계 v0.1 [WORKING DESIGN]》 (2026-10-22)
이 문서는 공개 저장소용 요약이며, 정본을 대체하지 않는다.

## 월드 방향

- 한강 중심의 역사·생활 오픈월드. 동일 장소를 시대별로 대조하되, 시대마다 하천·해안선·도로·지형은 별도 데이터로 관리한다.
- 단독 엔진을 신설하지 않고 기존 WorldForge / KOREA 프로토타입의 시장·골목·숲길, 상호작용·청크 로딩·저장·한지 지도를 승계한다.

## 조선 마포 생활권 배치 (기준선)

- 청크 단위 64×64m, 전체 구상 3열×4행 12청크. 좌표는 게임용 도식 로컬 좌표다.
- 기본 흐름: 북쪽 숲길 → 주거 골목 → 시장 → 남쪽 마포나루/한강.
- 기존 3청크: 숲길 Z[-160,-96], 주거 골목 Z[-96,-32], 중심 시장 Z[-32,32] (전부 중앙열 X[-32,32]).
- 신규 2청크: 마포나루 X[-32,32] Z[32,96], 갈대 물가 X[32,96] Z[32,96].
- 초기 대표 루프: 숲 장작 수집 → 시장 조리/제작 → 나루터 운송/갈대 물가 낚시 → 시장 판매·배달.
